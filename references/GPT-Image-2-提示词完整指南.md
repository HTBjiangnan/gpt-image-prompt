## 一、核心原则

### 核心公式

> **主体 + 风格/介质 + 场景/环境 + 比例（可选）**

GPT Image 2 理解力大幅提升，无需长篇描述。一句话能说清的不要写三句。

### 精修要点

| 要点 | 说明 |
|------|------|
| **风格优先** | "苹果风格"/"杂志风"/"国潮"比描述具体参数更有效 |
| **指定比例** | `1:1`/`2:3`/`16:9`/`9:16`/`4:5`/`3:2` |
| **中文标注** | 加"中文排版精准"强调文字准确性 |
| **留白技巧** | 需后期叠加人物/文字时，直接留出空白区域，不画边框 |
| **明亮积极** | 早安海报避免阴暗色调，用"清晨阳光"、"金色曙光" |
| **车窗真实感** | 加"半透明车窗"、"前中后景深"、近景元素划过 |
| **负面约束** | 明确排除不要的元素：`no watermark / no text overlay` |

## 二、八段式进阶结构

```
[风格定位] → [构图方法] → [主体描述] → [背景环境] → [光影氛围] → [色彩体系] → [技术参数] → [负面清单]
```

| 段 | 要点 | 示例关键词 |
|----|------|-----------|
| **风格定位** | 最关键，一句话定调 | `cinematic`, `editorial`, `neo-Chinese`, `Apple-style` |
| **构图方法** | S形曲线、撕纸裂痕、双重曝光、仰拍低角度 | `S-curve`, `torn paper`, `double exposure` |
| **光影设计** | 决定质感 | `dramatic warm lighting`, `rim lighting`, `glow from within` |
| **色彩体系** | 高级感秘诀 | `amber-gold`, `black-and-gold`, 电商色调库 |
| **材质质感** | 真实感关键 | 透明产品用`condensation droplets`+`glow from within` |
| **参数占位** | `{argument name="变量" default="值"}` | 品牌名、颜色、文字内容可变量化 |
| **负面约束** | 保持干净 | `no watermark, no plastic skin, no busy background` |
| **技术参数** | 比例、分辨率、景深 | `9:16`, `8K`, `shallow depth of field` |

### 高频构图技法

- **S形曲线构图**：蜿蜒河流/丝带引导视觉动线 → 内叠加双重曝光 → 流动感+双重叙事
- **撕纸/裂痕效果**：纸艺剪影立体感 → S形撕纸分割 → 内露东方山水/城市 → 边缘飞白留白
- **双重曝光融合**：人物剪影 → 变形为自然元素（河流/山脉/云雾）→ 叠加城市手绘图
- **仰拍低角度**：`low angle upward shot` → 巨型主体+渺小人物对比 → 宏大氛围

### 电商产品色调库

| 品类 | 配色方案 |
|------|---------|
| 高端香水 | 深棕+金+黑+白纹大理石 |
| 温和护肤品 | 奶油白+淡黄渐变+薄荷绿 |
| 热带汽水 | 明亮蓝+翠绿+橙黄+高饱和 |
| 奢华皮具 | 哑光黑+焦糖棕+金色金属 |

### 3.2 版式选择优先级规则

1. **内容信息密度**：信息多 → 多列/网格/拼图；信息少 → 大字+留白
2. **视觉情绪**：冲刺/热血 → 火红+动势构图；文化/雅致 → 水墨+留白；高端/克制 → 金属+大留白
3. **是否有参考图**：有 → 双列编辑逻辑（改什么/保留什么）；无 → 自由发挥但需锁定风格词
4. **比例优先**：竖版9:16（社交传播） / 横版16:9（PPT/主KV） / 方版1:1（电商）
5. **品牌一致性**：已有KV → 继承其配色/字体/印章；新项目 → 先定风格再写内容

### 23. 节气/抽象概念 × 高定礼服设计稿

**四步法：** 拆解主题 → 翻译意象 → 固定版式 → 严控质感

**封面版式（16:9）：** 左42%留白标题区 + 右58%视觉内容区，清楚边界
**正文版式（3:4）：** 中央真人模特 + 左上灵感草图+色卡 + 右侧技术线稿+法文备注 + 纯白背景+设计师笔记

### 29. 路人视角/偷拍感真实照片

> 核心方法论：**主动制造缺陷（劣化画质+前景遮挡+不完美构图）来获得真实感**，与传统"高清/完美/4K"思路相反。

**基础模板（带参考图使用）：**
```
A casual smartphone snapshot of a person recreating the character from the reference image.
Gender, face structure, body type MUST strictly match the reference — no gender swap.

CRITICAL — Face must be directly copied from the reference image: same face shape, same eyes (shape, size, spacing), same nose, same mouth, same jawline. Do NOT replace with a model's own face — the person should be recognizable as the same person in the reference. NOT a generic attractive face.

Character match: same hairstyle, same accessories, identical outfit structure.
[场景], subject at another table/area.

Skin: natural, visible pores, oily shine from [热源], slight redness, tiny imperfections.
Expression: NOTICEs the camera, turns slightly, gives a small casual [手势]. Spontaneous.

Framing: taken from YOUR table — your [前景物体] dominates foreground. Subject off-center, awkward crop. Your arm partially blocks frame. Foreground slightly out of focus.

Camera quality: bad composition, slightly tilted, minor motion blur, focus slightly off, visible grain, JPEG artifacts, lens smudge/greasy blur, finger slightly covering corner. Raw smartphone snapshot — NOT professional.

Lighting: mixed warm + cool indoor. Skin reflections, [蒸汽/雾] diffusing light, uneven exposure.
```

**关键技巧：**

| 技巧 | 作用 |
|------|------|
| **前景遮挡法** | 自己桌的物体挡住画面下半，制造"隔桌偷拍"视角 |
| **劣化画质** | JPEG压缩+手震模糊+手指遮角+油污镜头模拟手机急拍 |
| **不对焦** | focus slightly off + minor motion blur 模拟着急抓拍 |
| **角色还原** | 逐项指定五官形状/位置/间距，"NOT a generic face" |
| **性别锁定** | no gender swap + 严格匹配参考图 |
| **互动瞬间** | NOTICEs the camera → 自然回应，非摆拍 |
| **皮肤真实感** | 油光/微汗/泛红/毛孔可见，避免过度美化 |

### 30. 2D界面元素破框而出（社交媒体/截图破框创意）

> 核心方法论：**倒推式提示词设计** — 先问"这张图的核心冲突是什么？"，再倒推每个元素为何存在。

**核心冲突定义法：**
```
传统思路：堆风格词（电影感+赛博+超真实+未来感）→ 画面不一定成立
倒推思路：先定核心冲突 → 再建画面 → 每个元素都有理由
```

**常见冲突类型：**
- **二维界面 vs 三维角色** — 秩序化 UI vs 破坏式突破
- **屏幕里 vs 屏幕外** — 数字身份实体化，冲到现实面前
- **平面 vs 立体** — 截图被撕裂，元素从平面中挣脱

**四步结构：**
1. **保留原始素材识别度**（基于上传的截图/参考图，让观众认出来源）
2. **注入核心冲突/视觉爆点**（撕裂、冲出、破框、脱离屏幕）
3. **用光影和材质把"广告感"压出来**（提升完成度）
4. **收尾补控制条件**（比例、禁止项、文字）

**模板：**
```
A creative 3D photo manipulation of [原始界面类型], based on the uploaded [截图/参考图]。
[角色/元素] breaking out of the screen — [动作描述，如冲出/撕裂/悬浮]。
保留原界面的[关键UI元素]作为识别锚点，同时制造[冲突动作]。
[光影描述]，[材质描述]，[背景处理]。
禁止：界面变形失真、角色与界面关系混乱、过多文字遮挡主体。
```

**实操例子——社交媒体头像破框而出：**
```
A creative 3D photo manipulation of a social media profile interface,
based on the uploaded profile screenshot.

The profile avatar character is breaking out of the screen —
full-body 3D figure emerging from the flat interface, one hand reaching toward viewer,
UI elements (buttons, text blocks, icons) scattering and lifting off the surface
with visible depth and shadow.

The original profile layout remains recognizable as the base layer,
but the page appears torn, cracked, or warped where the character exits.
Warm cinematic lighting from upper left, dramatic rim light on the character.
Glossy glass-like fragments of the UI floating around the figure.
Shallow depth of field, subtle motion blur on flying UI pieces.

禁止：界面完全变形失真、角色悬空无支撑、UI元素过于凌乱遮挡主体。
```

**为什么有效：**
- 头像冲出来 → 代表**身份**（数字身份实体化）
- 页面被撕开 → 代表**突破**（从二维挣脱到三维）
- UI不能乱 → 一乱表达就散了（秩序感是冲突的锚点）

## 五、进阶技巧速查

| 技巧 | 说明 |
|------|------|
| **风格锚定** | 用经典风格词快速定位：`1960s French New Wave` / `35mm film` / `Studio Ghibli` |

| **双向对比** | 两个方案并列对比展示 |

### 10.2 GPT Image 2.5 专属方法论（全网实践提炼）

与 2.0 相比，2.5 在**编辑一致性、结构化布局、透明背景**上有实质升级，提示词写法相应变化：

**① 编辑用「双子句」结构（最重要变化）**
- 第一子句：只说改什么（一件事）。
- 第二子句（要写长）：逐项列出**必须保持完全不变**的内容。
- 2.5 对显式「keep X identical」指令的遵循度远高于 2.0，多数人败在保留清单写太短。
- 本指南场景 38 的双列逻辑在 2.5 上依然成立，保留列要更详细。

**② 链式编辑，一次一改**
- 2.5 的多轮编辑一致性是主打升级，但一次塞五个改动会互相污染；需要精确控制时逐轮单改。

**③ 风格靠具名光学细节，不靠形容词**
- 「电影感」无效；有效写法：相机类型 + 布光 + 颗粒感 + 调色，如「vintage film camera style, soft studio lighting, subtle grain, warm nostalgic palette」。
- 与本指南第五章「光线类型+方向+效果」规则互相印证。

**④ 排除项 2-3 个为宜，不写长清单**
- 实测长否定清单会让画面变平、变字面；只保留真正要紧的 2-3 条禁止项。

**⑤ 参考图要指定控制权**
- 只说「用这张图」得到的是氛围；必须点名参考图控制哪些特征（脸型/服装/姿势/材质）并要求延续到新画面。
- 本指南 V 编号版式库的参考图改造即此逻辑的中文实践。

**⑥ 透明背景需显式声明**
- 2.5 的 alpha 通道处理显著增强，但要写明「transparent background, no background fill」，适合出贴纸、图标、贴片素材。

**⑦ 结构化布局写法升级**
- 海报/信息图类提示词像写规格书：几个标注框、在哪侧、标签文字逐一列出；文字渲染继续用引号锁定 + 字重 + 位置（对应本指南核心原则）。
- 部分高星案例直接用 JSON 结构写信息图提示词，复杂版面可借鉴。

**⑧ 模型分层（API 侧）**
- `gpt-image-2.5-flare`：快速迭代、批量生成（对应本指南日常出图）。
- `gpt-image-2.5-sunburst`：高精度单次编辑（对应终稿修图）。

### 10.4 实拍照片 12 玩法（来源：数字生命卡兹克 2026-09-28）

#### 基础玩法

**1. 消除背景游客**
```
保持图片画面完全不变，仅将背景中的其他人和杂物去掉。
```

**2. 自动调光**
```
这张照片背景曝光太严重了，请以一个专业摄影师的身份，为这张图调一下光线、色彩和清晰度
```

> 进阶：ChatGPT 图片编辑界面「添加评论」功能——点击图片指定位置直接发编辑需求（如天空转黄昏蓝调、去掉杂物、顺头发），其余区域零偏移。

**3. 专业美颜（保留辨识度）**
```
根据照片中人物的实际脸型、五官与气质，进行有针对性的美容美学优化，并直接呈现自然修饰后的效果：调整适合本人的发型、分缝与蓬松度，整理眉形，适度提亮眼下、均匀肤色、淡化痘印，改善唇部状态，必要时加入轻淡自然的妆容，让整体更协调、有精神。除此之外的一切全部不变
```
